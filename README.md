# My Own Flag

A Processing application written in Java that programmatically draws a custom flag design featuring a central crescent moon and star patterns.

## Features

* **Crescent Moon (`Moon`):** Uses overlapping ellipses to render a detailed moon motif against a dark background.
* **Star Formations:** Employs geometric transformations and matrix stack manipulations (`pushMatrix`, `popMatrix`, `rotate`) to draw 5-pointed stars.
* **Pattern Layouts:** Arranges stars dynamically around the borders and in diamond structures using nested loop logic.

## How to Run

1. Clone or download this repository.
2. Open the project in your Java IDE (IntelliJ IDEA, Eclipse, or VS Code).
3. Ensure the **Processing core library** (`core.jar`) is added to your project dependencies/classpath.
4. Run `Main.java`.

## Requirements

* Java JDK 8 or higher
* Processing 3/4 `core.jar` library
